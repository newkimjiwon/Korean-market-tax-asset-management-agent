# 처음 사용하는 분: 계산 전에 준비할 것

직장인의 연말정산 예상 세금과 환급액을 확인하려면 **급여명세서의 항목별 금액**이
필요합니다. 자료를 모두 모으지 못했어도 시작할 수 있습니다. 모르는 값은
“모름”이라고 알려주세요. 확인하지 않은 금액을 0원으로 입력하지 않습니다.

## 먼저 계산할 기간을 정하세요

- 어느 해 소득을 계산할지 알려주세요. 소득이 발생한 해가 귀속연도입니다.
- 올해 연말까지 예상하려면 연간 예상 급여·상여와 앞으로의 납부 계획을 사용합니다.
- 연도가 끝난 뒤에는 연간 누계 또는 근로소득 원천징수영수증으로 확인합니다.
- 중도 입사·퇴사·이직·휴직이 있으면 해당 날짜와 이전 회사 자료도 필요합니다.

최근 한 달 명세서로도 예상 계산을 준비할 수 있지만, 한 달 금액에 무조건 12를
곱하면 상여·급여 변경·보험료 정산·근무기간 차이가 빠집니다. 월 금액인지 연간
누계인지 구분하고, 앞으로의 예상분을 별도로 확인해야 합니다. 도구는 월 금액을
자동으로 연간 환산하지 않습니다. 연간 실적은 `actual`, 연말까지의 예상은
`forecast`로 입력합니다.

## 가장 먼저 준비할 자료

| 준비할 정보 | 어디서 확인하나요? | 왜 필요한가요? |
|---|---|---|
| 연간 급여·상여 합계, 그중 비과세 급여 | 급여명세서·회사 연간 급여내역 | 세금 계산의 출발 금액입니다. 통합 도구에는 비과세 포함 급여와 비과세 금액을 각각 입력합니다. |
| 국민연금 등 공적연금 본인 부담액 | 급여명세서의 공제 내역 | 소득공제를 계산합니다. |
| 건강보험 본인 부담액 | 급여명세서의 공제 내역 | 보험료 소득공제에 사용합니다. |
| 장기요양보험 본인 부담액 | 급여명세서의 공제 내역 | 건강보험과 분리해 입력합니다. |
| 고용보험 본인 부담액 | 급여명세서의 공제 내역 | 보험료 소득공제에 사용합니다. |
| 이미 낸 소득세 | 급여명세서·원천징수 내역 | 최종 세금과 비교해 환급·추가 납부액을 계산합니다. |
| 이미 낸 지방소득세 | 급여명세서·원천징수 내역 | 지방소득세의 환급·추가 납부액을 따로 계산합니다. |
| 근무 시작·종료일, 다른 소득 유무, 거주자 여부 | 근로계약·본인 확인 | 계산할 기간과 지원 범위를 확인합니다. |
| 본인 외 기본공제 대상 가족 수 | 가족별 공제 요건 확인 | 인적공제에 사용합니다. 단순 동거 인원과 다릅니다. |

**“급여에서 공제되는 금액 합계”나 “실수령액”만으로는 부족합니다.** 합계에는
보험료·세금·기타 공제가 섞일 수 있습니다. 위 여섯 항목을 각각 확인해주세요.
보험료는 회사 부담분을 제외한 본인 부담액을 사용합니다. 건강보험에 장기요양이
합쳐져 표시돼 있으면 세부 내역을 확인해 중복 입력을 피합니다.

소득세·지방소득세는 이미 낸 금액을 입력합니다. 계산 결과인 최종 결정세액을
기납부액 칸에 넣지 않습니다. 원천징수영수증을 이용한다면 회사에 항목을 확인할
수 있습니다.

## 해당하는 항목만 추가로 준비하세요

| 해당 상황 | 준비할 정보·자료 |
|---|---|
| 중소기업 취업자 소득세 감면 | 적용 여부, 확인된 감면율, 최초 시작일·종료일, 해당 연도 감면 대상 급여. 회사의 감면 적용 내역을 확인합니다. |
| 월세 납부 | 관리비 제외 월세, 대상 월·납부일, 계약·전입 기간, 무주택·세대주/세대원 여부, 계약 및 주택 요건 확인. 임대차계약서·이체 내역을 참고합니다. |
| 공적 월세지원 수령 | 지원 대상 연월, 대상 월별 금액, 수령일. 지원 결정 안내와 입금 내역을 참고하며 대상 월과 입금 월을 구분합니다. |
| 연금저축·IRP 납입 | 해당 연도 본인 납입액을 각각 확인합니다. 회사의 퇴직연금 부담금은 제외합니다. |
| 카드·의료비·교육비·주택 관련 공제 | 간소화자료 등과 자격·한도 확인 자료. 통합 정산은 이 항목들의 원자료를 자동 계산하지 않으므로 검증된 공제액이 필요합니다. |
| 기부 | 기부 종류·금액·연도·영수증, 이전 연도 이월 내역. 현재는 종류별 한도·이월액 자동 계산을 모두 지원하지 않으므로 기부금액만으로 정확한 공제액을 확정하지 않습니다. |

감면이나 납입이 실제로 없으면 “없음”이라고 알려주세요. 월세지원도 없음을 확인해야
합니다. 모르는 경우와 없는 경우를 구분하면 불필요한 질문을 줄일 수 있습니다.

## 자료가 부족하면 무엇을 볼 수 있나요?

- 세금 계산에 필요한 급여·보험료·공제 정보가 빠지면 최종 세금은 확정하지 않고,
  필요한 항목과 다음 질문을 안내합니다. 부분 입력을 곧 완성된 계산으로 보지는 않습니다.
- 세금 계산 자료는 있고 기납부 소득세·지방소득세만 모르면, 최종 예상 세금은
  계산할 수 있지만 환급·추가 납부액은 정보 부족으로 표시합니다.
- 금액이 모두 있어도 미래 예상분이 포함되거나 해당 연도 규칙의 전체 검증이
  끝나지 않았으면 결과는 예상값(`provisional`)입니다. 현재 통합 정산의 2025·2026년
  규칙도 전체 검증 완료 상태는 아닙니다.

**최종 세금**은 공제·감면을 반영한 부담액이고, **환급액**은 이미 낸 세금이
그 부담액보다 많을 때 돌려받는 차액입니다. 공제 가능액이 곧 환급액은 아닙니다.

## 대화로 시작할 때 사용할 작성 목록

아래 제목을 복사해 확인한 값만 알려주세요. 문서 전체나 식별정보를 보낼 필요는 없습니다.

- 귀속연도 / 연간 실적 또는 연말 예상:
- 급여·상여 합계(비과세 포함) / 그중 비과세 금액:
- 금액의 기준 기간(한 달·연간 누계·연간 전체):
- 국민연금 등 공적연금 / 건강보험 / 장기요양보험 / 고용보험 본인 부담액:
- 이미 낸 소득세 / 지방소득세:
- 해당 연도 근무기간 / 다른 소득 유무 / 거주자 여부:
- 본인 외 기본공제 대상 가족 수:
- 중소기업 감면 / 월세 및 지원금 / 연금저축·IRP / 기타 공제: 해당 여부
- 아직 모르는 항목:

JSON에서는 모르는 필드를 생략하거나 `null`로 전달합니다. “모름”이라는 문자열을
금액 칸에 넣지 않습니다. 확인된 없음만 `0`, `false`, 빈 목록으로 표현합니다.
상세 필드와 조건별 질문은 `describe_settlement_fields`에서 확인할 수 있습니다.

## 개인정보와 실제 실행

이름·회사명·주민등록번호·상세 주소·계좌번호는 계산 입력에 필요하지 않습니다.
실제 자료를 저장소의 예제·테스트 파일에 적거나 커밋하지 마세요. 대화·도구 출력의
보관은 사용하는 호스트의 정책에 따르므로, 계산기가 파일을 만들지 않는다고 해서
대화 기록까지 남지 않는다는 뜻은 아닙니다.

개인정보 없이 동작을 확인하려면 저장소의 합성 예제를 그대로 실행하세요.

```bash
uv sync --extra mcp --extra dev
uv run python -m ktax examples/synthetic_settlement.json --json
```

개발자용 입력 형식·지원 범위는 [근로자 통합 정산](salary-settlement.md)을 참고하세요.
