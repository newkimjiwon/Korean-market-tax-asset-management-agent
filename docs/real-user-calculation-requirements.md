# 실제 사용자 계산 사례와 개선 요구사항

2026-09-13 대화 및 개선 전 코드 검토 기준의 요구사항 기록. 실제 구현 및 남은 범위는 [근로자 통합 정산](salary-settlement.md)을 참조한다. 확정 세액 결과 문서가 아니다.

## 개인정보 처리

실제 사용자 수치·나이·회사·거주지·지급 일정은 저장하지 않는다.
이 문서는 대화에서 드러난 일반적인 제품 요구사항만 기록한다.
예제와 테스트에는 실제 사례와 독립적으로 만든 합성 데이터를 사용한다.

## 개선 전 코드의 제약

1. `rules/data`에는 2025년만 있으며 2026년 호출은 실패한다.
2. `Profile.comprehensive_income`은 총급여를 그대로 합산한다. 근로소득공제와 본인 기본공제도 호출자가 `income_deductions`에 계산해 넣어야 한다.
3. `estimate_tax`는 공제 총액을 받는 구조이며 근로소득세액공제·감면 적용 순서와 상호작용을 계산하지 않는다.
4. 중소기업 감면의 적용 중 상태가 없다. 카탈로그는 현재 나이와 취업 연도로 신청 액션을 만들며 감면 대상 급여와 정확한 종료일을 표현하지 못한다.
5. 월세 총액만 있어 지원금·계약·전입·납부기간을 검증하지 못한다. 무주택과 세대주를 하나의 불리언으로 합쳐 두었다.
6. 각 액션을 같은 기준 프로필에 독립 적용한다. 이미 적용한 혜택과 신규 행동의 추가 절감액을 구별하고 여러 공제의 합계 한도를 계산하는 통합 경로가 없다.
7. 추천에는 누락값 점검이 있지만 `estimate_tax_liability`는 `_profile` 기본값을 그대로 계산한다. 미확인 소득·공제가 0으로 해석될 수 있다.
8. 기납부세액 필드가 없어 최종 부담액과 환급액을 분리 계산할 수 없다.
9. 질문 문구에 '작년'이 고정돼 있어 2026년 중간 예상 계산에 맞지 않는다.

## 구현 우선순위

### P0: 통합 계산 및 불완전 입력 처리

- 총급여 → 근로소득공제 → 소득금액 → 인적·보험료 등 소득공제 → 과세표준 → 산출세액 → 감면 → 조정된 세액공제 → 결정세액 → 기납부액과 정산 순서를 하나의 계산기로 구현한다.
- 사용자의 원자료와 계산으로 도출한 금액을 분리한다. 공제 총액과 세부항목을 동시에 받으면 이중 계산하지 않도록 입력 방식을 명시한다.
- 귀속연도별 근거·시행일·검증 범위를 관리한다. 2025년 데이터를 복제해 2026년 검증 완료로 표시하지 않는다.
- 결정세액과 환급액 각각에 `complete`, `provisional`, `indeterminate`, `unsupported_year` 등 계산 가능 상태를 반환한다.
- 가정·누락값·필요한 다음 질문을 계산 결과에 함께 반환한다. 세액에 영향이 없는 누락 항목은 후순위로 둔다.

### P1: 이번 사례를 표현하는 데이터

- 감면: 적용 여부, 감면율, 시작·종료일, 감면 대상 급여, 올해 적용액 및 원천.
- 주거: 계약기간·계약자 관계·전입일·무주택 여부·세대 지위·주택요건.
- 월세 및 지원: 납부액, 납부일, 대상 기간, 지원사업·지원액·대상 월·수령일.
- 급여: 귀속 기간, 과세·비과세 급여, 보험료 본인 부담액, 원천징수세액.
- 각 값에 출처, 기준일, 실적/예상 구분을 붙이고 명시적 미확인 상태를 유지한다.

### P2: 추천 및 질문 개선

- 이미 적용 중인 감면을 신규 신청으로 추천하지 않는다.
- 모든 추천은 동일한 통합 계산기의 적용 전후 차이로 계산한다.
- 법정 공제 가능액, 실제 사용액, 신규 행동의 추가 절감액을 구분한다.
- 결정세액이 이미 0이면 추가 납입으로 올해 환급이 증가한다고 설명하지 않는다.
- 사용자가 공제 총액을 직접 계산하게 하지 않는다. 급여명세서·원천징수영수증·간소화자료·계약 및 지원내역에서 항목을 수집한다.
- 신분번호·정확한 주소·계좌번호는 산술 계산에 요구하지 않는다. 자격 검증에 필요한 관계·주소 일치 여부 등을 사용한다.

## 수용 기준

- 일부 사실만 넣으면 누락값을 0으로 바꾸지 않고 필요한 가정과 다음 질문을 반환한다.
- 합성 시나리오에서 월세 총액과 공적 지원액을 구분한다.
- 다른 귀속연도에 속하는 지원분을 올해 월세에서 차감하지 않는다.
- 연중 감면 만료, 이직, 뒤늦은 전입, 월세 변경을 날짜 기준으로 처리한다.
- 원천징수액이 없으면 환급액은 미확정으로 남긴다. 결정세액이 0이라는 결과만으로 환급액을 만들어 내지 않는다.
- 대화 중 수기 계산을 검증된 정답으로 테스트에 고정하지 말고, 독립적인 공식 계산 사례와 대조한다.

## 구현 결과

- 통합 계산·누락값 질문·기납부 정산·중복 입력 방지와 기간 검증을 추가했다.
- 기존 적용 중인 감면과 월세 신청 상태, 추가 납입의 실제 절감액을 구분한다.
- 여러 원천의 필드별 출처·귀속연도·실적/예상을 보존하고 동일 권위 충돌은 계산을 멈춘다.
- 2025·2026년 통합 규칙을 추가하되 전체 연도 검증 미완료를 결과에 표시한다.
- 실제 데이터 없이 독립 합성 예제·경계 사례 테스트를 추가했다.
- 남은 범위: 기타 공제 원자료 자동 산출, 혼합소득·특례, 공식 신고 단수처리 및 연간 전체 검증.
